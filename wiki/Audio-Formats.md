# Audio Formats

[← Home](Home.md)

| Format | Typical purpose |
|---|---|
| MP3 | Small compatible music/speech files |
| WAV / PCM | Uncompressed recording or studio interchange |
| FLAC | Lossless archival |
| AAC / M4A | Mobile media |
| Opus | Efficient voice/music compression |
| OGG / Vorbis | Open audio distribution |
| AIFF | Uncompressed production workflows |
| ALAC | Apple lossless format |
| WMA / AC3 | Optional build-specific capability |

Compatible MP4, MKV, MOV and WebM files may expose audio streams for extraction.

**Actual decode/encode compatibility depends on the platform build.** A source compressed with a lossy codec cannot be restored to its original quality by converting to WAV/FLAC.
