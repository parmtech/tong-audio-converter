# Getting Started

[← Home](Home.md)

**Project status:** Architecture and foundational development. This is not a runnable converter yet.

## What to expect
1. Choose an integration mode: native SDK, CLI or optional worker API.
2. Supply media you own or are authorized to process.
3. Query `capabilities()` so you know what your installed build supports.
4. Probe input media, specify output codec/settings, submit job and verify the result.
5. Build and test platform-native artifacts when the first real release is published.

The implementation and code examples will be added with Phase 1.
