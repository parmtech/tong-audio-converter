# Frequently Asked Questions

[← Home](Home.md)

### Is the converter ready to download?
No. The current repository publishes the implementation plan and engineering specifications. Verified releases will be linked when available.

### Will it require a powerful server?
Not necessarily. Most audio conversions can run locally with sufficient storage and a supported codec build. CPU, battery and memory usage vary by media and output settings.

### Does a cross-platform engine mean one binary?
No. The public API is portable; separate native builds are required for platforms and architectures.

### Does it guarantee that every YouTube link works?
No. Media acquisition depends on provider transport, authorization, service rules and the optional extractor. Local media conversion must continue to work independently.

### Can I use it in a commercial application?
Apache-2.0 generally permits commercial use of this project's original code under its terms. Bundled third-party codecs/libraries can impose additional obligations.

### Can I contribute?
Yes. Read [Contributing](https://github.com/parmtech/tong-audio-converter/blob/main/CONTRIBUTING.md).
