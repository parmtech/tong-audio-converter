# Open-Source Research

[← Home](Home.md)

| Reference | Key lesson |
|---|---|
| [FFmpeg](https://github.com/FFmpeg/FFmpeg) | Codec engine, probing, filtering and transcodes |
| [GStreamer](https://github.com/GStreamer/gstreamer) | Pipeline and plugin design |
| [Symphonia](https://github.com/pdeljanov/symphonia) | Rust-based decoding and metadata |
| [Rubato](https://github.com/HEnquist/rubato) | Resampling approaches |
| [RustAudio/dasp](https://github.com/RustAudio/dasp) | DSP primitives |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Optional provider source adaptation, not the codec engine |

**Policy:** learn from mature designs; import only compatible, reviewed dependencies with correct license and attribution. Separate input acquisition failures from codec failures.

[Complete research and third-party review](https://github.com/parmtech/tong-audio-converter/blob/main/docs/THIRD_PARTY_RESEARCH.md).
